# Logos Workspace

Semantic verification engine + formal library of reasoning anomalies.

- `public-logoslib/` – curated definitions + formal specs + seed material
- `private-heraclitus/` – Rust verification kernel
- `docs/` – architecture, LogosLang, business notes
- `archive-legacy/` – frozen historical prototypes
- `heraclitus-mvp/` – transitional MVP snapshot
- `scripts/` – explicit bootstrap tools

See `docs/architecture/` for the design rationale.
