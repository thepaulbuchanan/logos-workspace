## 2. Technology Transfer & Licensing Architecture
The core intellectual property of the Heraclitus engine is managed via a strict, multi-tier **Technology Transfer and Licensing Agreement (TTLA)** executed between the engineering founders and the Poetic SPV:
*   **The Invariant Assignment:** The founders execute an absolute, irreversible assignment of all foundational source code, engine patents, and algorithmic runtime assets straight into the Poetic SPV corporate treasury in exchange for core founder equity tranches.
*   **The Open-Source Bifurcation Contract:** Poetic Technologies, Inc. grants a perpetual, royalty-free, global license of the **LogosLang** specification grammar syntax rules to the public domain. This satisfies academic peer-review scrutiny and eliminates algorithmic black-box bias concerns.
*   **The Proprietary Moat Lock:** Poetic retains exclusive, un-forkable ownership of the high-velocity execution engine binaries, private cloud VPC connectors, and remote Oracle server API nodes. Third-party provers can read LogosLang, but they must utilize Poetic infrastructure for high-throughput enterprise validation runs.
