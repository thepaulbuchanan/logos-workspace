# Master Lemma: The False Dilemma Fallacy

## 1. Description
An informal fallacy that occurs when an argument presents two alternative options as the only possible configurations, intentionally or accidentally omitting legitimate intermediate options, grey areas, or alternative routes.

## 2. Text Example
- **Forced Alternative A:** "Either you support our strict compliance framework..."
- **Forced Alternative B:** "...or you completely hate organizational security."
- **Fallacy:** Eliminating the third logical state—such as a collaborator who supports security but disagrees with this specific parsing grammar toolchain.
