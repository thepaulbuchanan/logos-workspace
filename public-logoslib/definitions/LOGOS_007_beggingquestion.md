# Master Lemma: Begging the Question

## 1. Description
An informal fallacy where an argument's premises assume the absolute truth of the conclusion they are attempting to prove, rather than supporting it with independent evidentiary axioms. This creates an ungrounded closed logical loop.

## 2. Text Example
- **Premise 1:** "Smoking cigarettes is deadly because cigarettes can kill you."
- **Analysis:** The assertion relies on an internal tautological identity mapping (`Deadly == Can Kill`), providing zero external causal grounding.
