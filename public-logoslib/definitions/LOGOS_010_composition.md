# Master Lemma: Fallacy of Composition

## 1. Description
Occurs when an entity fallaciously infers that because an individual element or part of a system possesses a specific structural trait, the entire composite entity or system must inherently possess that identical trait.

## 2. Text Example
- **Element Attribute E:** "Every single component brick inside this architectural building weighs less than one pound."
- **Composite Inference C:** "Therefore, the entire structural building must weigh less than one pound."
- **Fallacy:** Failing to treat collective aggregate properties as fundamentally distinct from element properties.
