# Master Lemma: The Base Rate Fallacy

## 1. Description
Occurs when an entity makes a probability judgment based on conditional probabilities (e.g., the accuracy of a test), without taking into account the prior probability (base rate) of the target attribute within the parent population.

## 2. Text Example
- **Prior Base Rate P:** "Only 1% of the population has this condition."
- **Test Condition C:** "A test detects the condition with 99% accuracy, but has a 5% false positive rate."
- **Inference Claim:** "The user tested positive, therefore it is 99% certain they have the condition."
- **Fallacy:** Bypassing the fact that the absolute number of false positives in the remaining 99% of the population heavily outweighs the true positives in the 1% pool.
